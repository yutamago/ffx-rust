# Noise allow list of cdsp0000 (S.S. Winno deck, save slot 1): what differs
# between two runs of the original code at field-walk-1's frame (ctrl work
# 0's event count 101), from six captures (fw1..fw3, a and b; 15 pairs), and four
# (n1, n2) with the harness of 2026-10-24, which seeds the cloth jobs' CRT
# rand() per character and event frame: their cloth (vb5) no longer differs.
# docs/drawdiff.md, "Noise in cdsp0000".
[cdsp0000]

# Differs by 1 to 5 f32 ulp (3.4701328 to 3.470134) in 5 of 6 pairs of
# four captures made with the harness of 2026-10-24 (harness-main-thread);
# before it, 3 values 1 ms apart (3.436, 3.437, 3.435999). The virtual clock
# now starts at a fixed 2^20 s and steps exactly one frame interval a frame
# (ffx-hook harness.rs VIRTUAL_START, fast_sleep), which removed the f64
# rounding of the wall clock's FILETIME reading (8 ulp) and the frame
# limiter's ms truncation (1 ms). What is left is likely the game's own f32
# time since start (Phyre_PFramework_PApplication_frame 0x00627940 keeps it
# and the frame's dt as f32), whose rounding depends on how many frames the
# load took before the event started.
constant var=scene field=*.cb0.scene.GlobalTime cause: the game's f32 time since start rounds differently when the load took another number of frames (a few ulp)

# Differs in every pair, about 5e-30: the third word of the light vector
# Ch_DrawMain (0x0082ed50) passes to graphicSgSetSpecular (0x00643cc0) is
# [ebp-0x3c], a stack word it never writes (ffx_chara::draw_main; the port
# passes 0 under the junk-read policy of 2026-10-24).
constant var=SgSpec_LightVec field=*.SgSpec_LightVec[0].z cause: junk read, Ch_DrawMain never writes [ebp-0x3c] (the light vector's third word)

# The camera vector Ch_DrawMain (0x0082ed50) passes to graphicSgSetSpecular
# has a third word it never writes ([ebp-0x2c]). In the original it holds
# whatever an earlier call left on the stack (a stale integer 1, read as
# 1e-45); ported functions further up the stack leave other words there
# (h3-glue-render, 2026-10-25: 0x004c0000), and the port of Ch_DrawMain
# passes 0 (junk-read policy, 2026-10-24). The shader reads the variable;
# whether the word changes pixels is not checked here (the replays' shots of
# these frames match the original at 0 pixels).
constant var=SgSpec_CameraVec field=*.SgSpec_CameraVec[0].z cause: junk read, Ch_DrawMain never writes [ebp-0x2c] (the camera vector's third word); its value depends on what earlier calls left on the stack
