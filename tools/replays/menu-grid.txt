# the Strength node under the cursor (Power Spheres 99 -> 98, "Tidus's

# Circle answers it (as in coverage-session.txt). Then Aeons (Valefor's

# back to the field.
#
# Lockstep, fast mode; the menu opens at ctrl work 0's count 101
# (0x01325d94, as in field-walk.txt). After each node activation the
# message must run out (wait 60) before the next press, or the press goes
# elsewhere. No shots of the main menu: its play-time clock blinks
# (menu-browse masks it, tools/shot-compare.py MASKS).
#
# Ranges: the party records (0x0113205c, 18 x 0x94: stats, S.Lv, AP), the
# item inventory (g_SaveItemIds 0x0113095c, g_SaveItemCounts 0x01130b5c:
# the spheres), the sphere grid's save block (g_SaveAbilityMap 0x0112ec7c,
# 0x1320 bytes: activated nodes, positions), the party order
# (g_SaveInParty 0x011307e8, 0x14 bytes with the reserve), the active
# menu mask (0x018408ec).
# Screenshots (menu-grid-<n>.bmp): 1 the grid on Tidus, 2 Power Sphere 99
# picked, 3 "Strength increased", 4 "Move to this location?", 5 Tidus on
