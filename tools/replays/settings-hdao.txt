# Graphics settings (M4 coverage 2, docs/harness.md "Settings replays"):
# field-walk's deck (save ffx_001, cdsp0000, shadow solution 2) with
# HDAO=High (tools/sandbox/hdao.ini merged over the sandbox's
# GameSetting.ini, Quality=VQ_CUSTOM so the file's value counts). Reaches
# PostProcessManager_renderHDAOPass and its ring setup (g_Settings +0x48 ->
# pp +0x1264). Shots pinned to ctrl work 0's count as in field-walk.txt
# (101 and, after a short walk of a fixed 230 frames in lockstep, 331).
# Traced: the settings words (g_Settings 0x022fb504 -> +0x30..+0x4b:
# Shadow, TextureQuality, MSAA, ColorCorrection, PostAA, UnSharpMask, HDAO)
# so a settings file the game did not take shows up as a difference, the
# generators and the party records.

read 0x01325d94 4
