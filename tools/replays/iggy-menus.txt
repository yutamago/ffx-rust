# Iggy (Flash) screens (M4 coverage 2, docs/harness.md "Iggy screens"):
# the PC menu (Esc) and its pages, then the title and the load list, read
# only. From save ffx_001 (the deck, cdsp0000), lockstep, fast mode.
#
# The PC menu reads DirectInput keys (01 Esc, 1c Enter, 0e Backspace, c8
# up, d0 down). Its entries: Resume, System setting, Special features,
# Change parameters, Quit (never selected: it ends the process). Backspace
# goes back one page and puts the cursor on the page's first entry again;
# Esc closes the menu from any page. System setting lists Audio, Video and
# Key bindings. Enter on the Video page's first row (Resolution) opens its
# list, so the script never presses Enter there; nothing is changed or
# applied (each page is left with Backspace, which cancels).
# The Flash screens animate their transitions, so each shot comes 240
# frames after the key that opened the page.
#
# Then the title as after a game over (menu-save.txt: `call`
# AtelJumpGameOver 0x0086da10, map 0x17 by way of memochek and the opening,
# Start), Load (Enter): the save list (state 0xc of the save/load machine,
# g_SaveMachineState 0x00ce72e8; no shot: its dates are the files' times),
# and Backspace back to the title (state 0xa, idle). No save is written
# or loaded.
#
# Traced: the map words, the save/load machine's state and cursor
# (0x00ce72e8:0x18), the generators.
# Shots (iggy-menus-<n>.bmp): 1 the PC menu, 2 System setting, 3 Audio,
# 4 Video, 5 Video scrolled to its last row (UnSharp Mask), 6 Key bindings,
# 7 Keyboard bindings, 8 Special features, 9 Change parameters, 10 the
# field after Esc, 11 the title, 12 the title after leaving the load list.
load direct 1 cdsp0000 lockstep
lockstep on
pin
waitfor 0x01325d94:4 40000000 c0ffffff 1500
wait 37
trace 0x0112ca90:4 0x00ce72e8:0x18 0x00c42200:4 0x01135ee0:0x110
key 01 4 240
shot $OUT\iggy-menus-1.bmp
# System setting, Audio
key d0 4 60
key 1c 4 240

key 1c 4 240

# Key bindings, Keyboard

key d0 4 60
