# Draw captures (M4 references, docs/renderer.md "Reference captures"):
# hash-only Direct3D 11 captures of three field frames each, at the event
# counts field-walk.txt pins its shots to (ctrl work 0's frame count
# 0x01325d94: 101 and 459 on the salvage ship deck, cdsp0000, save
# ffx_001) and at event-besaid.txt's first shot (Besaid beach, bsil0000,
# save ffx_003, count 101). Needs the graphics layer (FFX_GFX=1); not part
# of run-all.sh (no trace, no shots to compare). Run it with
#   FFX_GFX=1 target/release/examples/replay tools/replays/draw-field.txt \
#     '<windows path of a folder>\draw-field.trace' [original]
# Captures land beside the trace ($OUT\fw-101, fw-459, besaid-101), about
# 3.5-6.3 MB each: keep them in ~/ffx-work/m4/captures, never in the
# repository. Two runs are compared with ~/ffx-work/m4/draw-field-gate.sh
# (drawdiff and the hashes.txt comparison; the noise list is in
# docs/renderer.md, "Reference captures").
#
# Each capture starts with `now` while lockstep holds the render thread in
# Present after a wait (the main thread then waits too), so it records the
# scene inputs as the main thread left them ("held") and the next three
# frames' calls; `async` answers at once and `wait 3` runs those frames;
# `gfxcapture result` gives the reply. The three frames shift the later
# inputs by 3, so the walk's last wait is 117 where field-walk has 120.
#
# Since 2026-10-27 (replay-flakes3) the load runs in lockstep (`load direct
# ... lockstep`, docs/harness.md "Lockstep from the load") and `pin` sets
# what the free frames before it leave ("Pinned state"), as in field-walk.
# Without them the update the captures fell on and the per-batch blink seeds
# (fw-101's draw 113: BC3 or BC1, docs/drawdiff.md) followed the machine's
# load. References: ~/ffx-work/m4/captures/ref2-{a,b,c}; the ref-{a,b,c}
# set was taken with the old form.
load direct 1 cdsp0000 lockstep
lockstep on
pin
waitfor 0x01325d94:4 40000000 c0ffffff 1500
wait 37
read 0x01325d94 4
shot $OUT\draw-field-1.bmp
gfxcapture $OUT\fw-101 hash frames 3 now async
wait 3
gfxcapture result
press up 40 10
press left 20 10
press down 40 10
press right 30 10
press circle 4 30
press circle 4 30
wait 117
read 0x01325d94 4
shot $OUT\draw-field-2.bmp
gfxcapture $OUT\fw-459 hash frames 3 now async
wait 3
gfxcapture result
# Besaid beach from save 3, as event-besaid.txt starts (the title is not
# shown again: `loadsave` starts the save from here)
loadsave 3
waitfor 0x0112ca90:2 4600 ffff 1500
waitfor 0x01325d94:4 00000000 c0ffffff 1500
waitfor 0x01325d94:4 40000000 c0ffffff 1500
wait 37
read 0x01325d94 4
shot $OUT\draw-field-3.bmp
gfxcapture $OUT\besaid-101 hash frames 3 now async
wait 3
gfxcapture result
