# Boot: what the game shows before any load, which the other replays skip
# (`load direct` taps Start once memochek.ebp opens, on its logo). From
# launch, with no input: the FINAL FANTASY X PROJECT logo (map 0x15c,
# memochek, on titl02), the opening (map 0x15d: credits on black, then the
# campfire scene with credits, in-engine, no FMV) and, after one Start, the
# title menu (map 0x17, previous 0x15d). No trace ranges; the screenshots
# (boot-<n>.bmp) are the check.
#
# Lockstep since 2026-10-27 (replay-flakes4). Until then `realtime`: the
# opening keeps time with the music stream, which played in real time, so
# in fast mode (461 frames a second) the same event frame showed a different
# camera cut, credit and pose in every run, original code included; at the
# game's own frame rate a frame of jitter was left (two original recordings
# 12,301 and 36,884 pixels apart on boot-2/-3). Since sound runs in
# lockstep (docs/harness.md, "Sound in lockstep") the music keeps the
# update count, so the replay runs in fast mode on the virtual clock, in
# lockstep from the first boundary after memochek's map is up, and pins
# there (`pin`: what the start-up loop's free frames left). A `lockstep on`
# sent before the main loop's first update used to hold every start-up
# present for 5 s and the boot never got to its first update; the main
# thread now takes the hold at its first boundary.
#
# Each shot is pinned to the event's clock, ctrl work 0's frame count
# (0x01325d94, as in field-walk.txt): `shotwhen` takes the image of the
# update after which the count first lies in a 4-aligned window. Map words
# are 0x0112ca90 (current map, previous map). Each `shotwhen` starts while
# the count is far below its window: one that matches on the first frame it
# checks fails (its image may be gone).
# 1: the logo, memochek's count 108
waitfor 0x0112ca90:4 5c011700 ffffffff 3000
lockstep on
pin
waitfor 0x01325d94:4 40000000 c0ffffff 600
shotwhen 0x01325d94:4 6c000000 fcffffff 600 $OUT\boot-1.bmp
# the opening's event: wait for its count to start again (0..63)
waitfor 0x0112ca90:4 5d015c01 ffffffff 3000
waitfor 0x01325d94:4 00000000 c0ffffff 600
# 2: Wakka, Rikku and Lulu at the fire (count 908; the wide shot before it
# pans)
waitfor 0x01325d94:4 00020000 00feffff 1200
shotwhen 0x01325d94:4 8c030000 fcffffff 1200 $OUT\boot-2.bmp
# 3: the party from behind Kimahri, Tidus getting up (count 1208)
waitfor 0x01325d94:4 00040000 00fcffff 1200
shotwhen 0x01325d94:4 b8040000 fcffffff 1200 $OUT\boot-3.bmp
# 4: Start skips to the title; the title event's count 108 (menu shown)
press start 3 0
waitfor 0x0112ca90:4 17005d01 ffffffff 600
waitfor 0x01325d94:4 00000000 c0ffffff 600
waitfor 0x01325d94:4 40000000 c0ffffff 600
shotwhen 0x01325d94:4 6c000000 fcffffff 600 $OUT\boot-4.bmp
