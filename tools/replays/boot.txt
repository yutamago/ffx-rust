# Boot: what the game shows before any load, which the other replays skip
# (`load direct` taps Start once memochek.ebp opens, on its logo). From
# launch, with no input: the FINAL FANTASY X PROJECT logo (map 0x15c,
# memochek, on titl02), the opening (map 0x15d: credits on black, then the
# campfire scene with credits, in-engine, no FMV) and, after one Start, the
# title menu (map 0x17, previous 0x15d). No trace ranges; the screenshots
# (boot-<n>.bmp) are the check.
#
# realtime: the opening keeps time with the music stream, which plays in
# real time. In fast mode (461 frames a second) the same event frame showed
# a different camera cut, credit and pose in every run, original code
# included, so this replay runs at the game's own frame rate, without
# lockstep. Each shot is pinned to the event's clock, ctrl work 0's frame
# count (0x01325d94, as in field-walk.txt), reached by waiting for it to
# enter a power-of-two range (`waitfor` with a mask) and then a fixed
# number of frames; the read-backs land in the replay's output. Map words
# are 0x0112ca90 (current map, previous map).
realtime
# 1: the logo, memochek's count 101
waitfor 0x0112ca90:4 5c011700 ffffffff 3000
waitfor 0x01325d94:4 40000000 c0ffffff 600
wait 37
read 0x01325d94 4
shot $OUT\boot-1.bmp
# the opening's event: wait for its count to start again (0..63)
waitfor 0x0112ca90:4 5d015c01 ffffffff 3000
waitfor 0x01325d94:4 00000000 c0ffffff 600
# 2: Wakka, Rikku and Lulu at the fire (count 900: 512 + 388; the wide
# shot before it pans, and a frame's jitter there differs everywhere)
waitfor 0x01325d94:4 00020000 00feffff 1200
wait 388
read 0x01325d94 4
shot $OUT\boot-2.bmp
# 3: the party from behind Kimahri, Tidus getting up (count 1200: 1024 + 176)
waitfor 0x01325d94:4 00040000 00fcffff 1200
wait 176
read 0x01325d94 4
shot $OUT\boot-3.bmp
# 4: Start skips to the title; the title event's count 101 (menu shown)
press start 3 0
waitfor 0x0112ca90:4 17005d01 ffffffff 600
waitfor 0x01325d94:4 00000000 c0ffffff 600
waitfor 0x01325d94:4 40000000 c0ffffff 600
wait 37
read 0x01325d94 4
shot $OUT\boot-4.bmp
