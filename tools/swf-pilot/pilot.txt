# M5 SWF pilot (crates/ffx-swf, docs/formats/pc-ui.md "Iggy calls"): the
# Iggy screens in several states each, for the Iggy-against-Ruffle
# comparison. Not on run-all.sh's lists (no recorded reference): it runs on
# the original code with the Iggy call log on, from
# tools/swf-pilot/record.sh. Inputs as iggy-menus.txt (DirectInput keys:
# 01 Esc, 1c Enter, 0e Backspace, c8 up, d0 down); nothing is changed,
# saved or loaded.
#
# Shots (pilot-<name>.bmp): the field before the menu (scene-esc), the PC
# menu opening (esc-open-<n>, n frames after Esc,
# every other frame: the animated comparison), idle (esc-idle), the cursor moving (esc-move-<n>), System
# setting sliding in (sys-<n>) and idle, Audio, Video, Key bindings; then
# the title after a game over, the load list opening (load-<n>), idle, the
# cursor moving (load-move-<n>), the "load this game?" pop-up and back.
